## 파일 역할별 분류

### 레이어 1: 사용자 인터페이스
```
commands/gsd/*.md → 사용자가 입력하는 명령어
hooks/*.js        → 자동 실행되는 훅
```

### 레이어 2: 오케스트레이션
```
get-shit-done/workflows/*.md → 명령어를 실행하는 워크플로우
```

### 레이어 3: 실행 엔진
```
agents/*.md                  → 전문화된 AI 에이전트
get-shit-done/bin/gsd-tools.js → CLI 상태 관리 도구
```

### 레이어 4: 지식 베이스
```
get-shit-done/references/*.md  → 기술 레퍼런스
get-shit-done/templates/*.md   → 문서 템플릿
```

### 레이어 5: 인프라
```
bin/install.js              → 설치 시스템
scripts/build-hooks.js      → 빌드 도구
package.json                → 패키지 정의
```
